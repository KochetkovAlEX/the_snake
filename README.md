# the_snake

## Реализация игры "Змейка" на языке Python
Данный проект выполнялся в целях курса "Ассоциированные программы: backend-разработчик" от компании Яндекс для изучения и повторения языка программирования Python


### Зависимости
- flake8==5.0.4
- flake8-docstrings==1.7.0
- pep8-naming==0.13.3
- pycodestyle==2.9.1
- pygame>=2.5.2
- pytest==7.1.3
- pytest-timeout==2.1.0

При установке pygame==2.5.2 возникала ошибка. Решением явялется установка более новой версии библиотеки. На функциона не влияет
